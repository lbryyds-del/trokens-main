# 外观对应绑定：冻结开发集诊断

> 历史记录，非当前运行说明。2026-11-06 已删除废弃实验代码和旧配置；当前入口及恢复方法见 [ρ 收敛记录](rho_cleanup_20261106.md)。本文原始实验叙述保留，不代表当前模型。

## 目的和边界

用户授权测试，不授权重训。原 rho、主匹配、checkpoint 均保持不变。
诊断使用训练快照的 epoch 3 双通道模型，不修改模型源文件或原配置。
输出：`output/sav/bound_change_audit_20261106_v1`。

目前主路径是帧原型 BiMHM，没有实际的簇对簇匹配边。
本实验新增的时间池化 Post 簇外观软对应是一个代理。
不能把代理上的正结果直接称为“核验了原主匹配实际依赖的对应”。
若代理无效，也不能断言所有主匹配绑定方案都无效。

## 文献核对

- [R2-VOS](https://arxiv.org/abs/2207.01203v3) 确实研究不配对的视频/文本，通过文本重建的结构循环约束处理语义不一致。它支持目标不存在的研究动机，不证明 SAV 误报的原因。
- [DOD §C.3](https://arxiv.org/html/2307.12813v2) 的二分类是区域和描述是否匹配的共享 VQA 任务，不能简单归为每个类别需要一个专属分类头。因此“新类别只能用对比核验”过强。
- [Query2Label](https://arxiv.org/abs/2107.10834) 使用标签查询汇聚视觉内容后做二分类；可作为条件化表示与存在性判断分离的相关工作。
- [QD-DETR](https://cvpr.thecvf.com/virtual/2023/poster/21845) 使用不相关视频-查询对及输入自适应显著性判据；不自动意味着本任务应该同时加入新阈值网络。
- [TANE](https://openaccess.thecvf.com/content/CVPR2022/html/Huang_Task-Adaptive_Negative_Envision_for_Few-Shot_Open-Set_Recognition_CVPR_2022_paper.html) 用生成的负原型学习任务相关拒绝边界。其未知类别拒绝与多标签 episode 内目标类别不存在不是完全相同的任务。
- [AAPM §3.1–3.2](https://arxiv.org/html/2502.12582v1) 的 episode 在同一属性内选类别，并对 Support 和 Query 都施加共享属性空间约束。不是完全不条件化 Query；也不是本任务逐候选动作的独立存在判断。比较需要说明协议改造，不能称完全同设置。
- [VCD](https://arxiv.org/abs/2311.16922) 对比原始/扰动视觉输入的生成分布。可以启发对照，但本模型不生成语言，候选表示的产生本身不等于已证明的幻觉。
- [CVNet](https://arxiv.org/abs/2204.01458) 用多尺度稠密相关与4D卷积学习检索核验，不只是传统内点计数。跨视频动作匹配的非刚性、视角、速度差异意味着不能照搬同实例几何一致性假设。

## 对照设计

A/B 沿用既有开发集录制前缀划分，每半2000 episodes，seed1。
两半都曾用于前期发现，当前 checkpoint 也由开发结果选定；本次不是独立最终泛化评测。
不读取完整测试池或 reserved 池，不改变训练集。

模型一次前向返回原始两通道分数，同时读取逐簇外观、状态变化和几何描述子。
软对应为 `exp(cos(appearance_q, appearance_s)/0.1)`，在每个正/负有效参考集合分别归一化。
只用已知 Support 标签划分正负。未知标签不算负例。没有使用 Query 真值来选择对应。

核心三组共享同一输入、参考筛选、有效性规则、无变化规则和乘性交互：

1. unbound：变化核验中的参考权重均匀。
2. bound：变化核验中的参考权重由外观软对应决定。
3. random_bound：在每个 Support 内打乱有效簇的外观关联，保留外观分数分布。

各通道使用同样的归一化 log-mean-exp 正负差、已训练温度/尺度和融合系数。
形成簇级联合变化证据 d_c 后，三组统一应用：

`delta = -10 * sum_c normalized_alpha_c * relu(appearance_positive_minus_negative_c) * (1-exp(-beta*relu(-d_c)))`

该交互只扣除外观正优势，没有重新定义主路径的外观分数。
beta 共7值：0、0.25、0.5、1、2、4、8，只在A上选择。
同时用相同7值校准当前模型的联合只否决版本，防止绑定只赢了未调强度的弱对照。
保留原rho路径、当前完整版、状态单路、几何单路、联合只否决/只加分作描述性对照。

没有有效正/负参考、无效观测时修正为0。
状态变化采用相对Post幅度阈值1e-3：成对两边均低于阈值时不作为变化证据。
这只是数值中性规则，不等于语义上静态动作自动安全。
几何沿用已训练分支的无运动/有效步数条件，不新增相机补偿。

## 检查及判定

- smoke：4个真实episodes，诊断hook必须不改变原输出，重建两路分数必须吻合，参数不能更新。
- A拟合后写入不可重选的 `locked_coefficients.json`，之后才计算B聚合指标。
- B报告HM的配对episode bootstrap，2000次。
- 高rho且原路径判阳性的样本，按类别、rho宽度0.1、原路径logit宽度1分组，报告变化贡献的AUC；小组至少10正10负。
- 新难样本对：episode内同类别、rho均>=0.8、原路径均判阳性、rho差<=0.05且原logit差<=1。不是旧2088对。
- 固定阈值和A上锁定的逐类召回匹配阈值下，报告误报、召回、纠错、误伤。
- 静态类别预先固定为sit/stand/look_forward；不以B结果重新分组。
- 共现按Query与该类正Support共享其他真实标签分组，只用于事后评估。
- 记录无参考与有效簇覆盖率；所有分支用同样的episode和采样特征。

仅当绑定相对不绑定/随机对照出现可靠增量且未明显伤害静态/共现样本，才值得讨论进一步训练。
即使通过，也只是支持当前绑定机制，不能证明“不可伪造”、文本偏置被消除或方法首次提出。
